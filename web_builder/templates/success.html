Jak zainstalować za pomocą FBI (Remote Install)?

  1. Podłącz swojego 3DS-a do tej samej sieci Wi-Fi co komputer.
  2. Uruchom aplikację FBI w menu głównym 3DS-a.
  3. Wybierz opcję Remote Install -> Scan QR Code.
  4. Zeskanuj powyższy kod aparatem konsoli i zaakceptuj instalację.

Zalecane: Jeśli Remote Install zawiedzie, pobierz plik ręcznie przyciskiem i skopiuj na kartę SD.
